### Added
- **Vigia externo da produção** (#2107): o GitHub Actions testa a cada 5 min, fora da VPS, a API (`/health/ready`), o console, o site e a loja. Se algum cair duas vezes seguidas, abre uma issue `uptime` atribuída ao responsável, e o app do GitHub avisa no celular. A issue fecha sozinha quando tudo volta. Custo zero e sem conta nova.
- **Observabilidade na VPS** (#2107): OpenObserve guarda por 30 dias os logs, traces e métricas da API, do Web e do Worker, que chegam por um collector OTLP interno. A tela abre pelo túnel SSH. Os logs dos containers passam a ter rotação, e o Worker ganha healthcheck no Docker por arquivo de vida. Tudo isso sobe com `scripts/deploy/observabilidade-deploy.sh`.

### Fixed
- **API sem exportar para o vazio** (#2107): sem `OpenTelemetry:OtlpEndpoint`, a API não registra mais provider nem exporter OTLP. Antes ela caía em `localhost:4317` e descartava traces e métricas em produção.
