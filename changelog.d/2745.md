### Security
- **Renovação de sessão no navegador com uso único de verdade** (#2745): o mesmo token de renovação, apresentado ao mesmo tempo por duas requisições, agora rende uma sessão nova só para uma delas; a outra é recusada como credencial inválida. É o mesmo consumo atômico que o app já usava. Quem estiver logado não percebe diferença.
